# Internship Portal

## Project Overview

Internship Portal is a simple and responsive website built using HTML and CSS.

The portal provides information about internship opportunities and includes the following sections:

- Home
- About
- Internship Programs
- Team
- Contact

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No additional installation or dependencies are required.
